BIRTHDAY SURPRISE — UNTUK BANG

Isi:
- index.html
- style.css
- script.js
- assets/happy-birthday.wav
- assets/foto-1.jpg sampai foto-4.jpg

Deploy ke GitHub Pages:
1. Upload seluruh isi folder ini ke repository.
2. GitHub → Settings → Pages.
3. Pilih branch utama dan folder root.
4. Simpan, lalu buka URL GitHub Pages.

Musik:
Website mencoba autoplay Happy Birthday ketika halaman dibuka. Browser tertentu memblokir autoplay bersuara; jika terjadi, satu klik/tap akan langsung menyalakan musik.
